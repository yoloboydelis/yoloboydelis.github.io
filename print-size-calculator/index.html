Where to print

Download the full-resolution file from the museum link, then upload it to a print shop. Pick a size at or below the 150 DPI figure for posters viewed from a metre away; use the 300 DPI size for sharp close viewing.

Recommended print path (Belgium / Netherlands)

  1. Download the museum file (link on each card).
  2. Upload it to a poster printer at or below the max size shown above.
  3. Order a matching frame if you want it wall-ready.
